# 🌐 Personal Portfolio Website

A responsive personal portfolio website showcasing my skills, education, projects, resume, and contact information as an aspiring software developer.

## 📌 About the Project

I developed this portfolio to build my professional online presence and showcase my technical skills, projects, and learning journey.

The website provides an overview of my background and allows recruiters, developers, and visitors to connect with me.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## ✨ Features

- Responsive and modern user interface
- Home section with introduction
- About Me section
- Technical Skills section
- Projects showcase
- Education details
- Downloadable resume
- Social media links
- Functional contact form using Formspree

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/ShivaniBorban/shivani-portfolio.git
```

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server.
